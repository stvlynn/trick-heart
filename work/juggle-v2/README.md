# 抛球、合帘、转头修复

新增 13 张完整人物抛球原画与 3 张转头原画。覆盖 2472–2784 帧及 3356–3396 帧。三个抛球机位共用完整动作原画，按原片领口锚点整体对齐。合帘期间继续替换人物，并恢复原片幕布前景。转头按正面、右、左、右、左切换。
